REVIEW CHECKLIST

01. Work typed during a save can disappear
IMPLEMENTED. The app saves a captured snapshot and tracks subsequent edits by
change number. A response updates the saved base/revision without replacing
newer text. Newer changes stay in a protected draft and are saved afterward.
VERIFIED: delayed-save regression confirms the later text remains dirty and
protected, then reaches storage in the next save.

02. Two tabs can silently overwrite each other's changes
IMPLEMENTED. SQLite writes require the expected revision. A stale update gets
HTTP 409 with the current record. The interface performs a three-way comparison,
combines independent edits, and presents conflicting values for a choice.
Duplicated browser pages receive separate draft keys.
VERIFIED: HTTP, threaded-concurrency, merge regressions and real two-tab browser
workflows. Exactly one of two competing writes wins; the other cannot overwrite.

03. Canceling another action can disable draft protection
IMPLEMENTED. Opening or closing a modal does not mark the dossier as saved.
Navigation waits for a confirmed save, and failures leave the current draft
protected. Read-only views do not create or clear dossier draft state.
VERIFIED: cancel/read-only dialog and pending-save regressions.

04. Finding dialogs do not protect unfinished entries
IMPLEMENTED. Unfinished fact, source, identity, task and dossier forms are stored
locally. Close/Escape keeps them, Discard explicitly removes them, and Recover
drafts can resume or download them. Pending submissions disable form editing and
closing; before-unload protection includes unfinished entries.
VERIFIED: source-plus-fact draft recovery in DOM and Chromium workflows.

05. Write actions can be submitted repeatedly while pending
IMPLEMENTED. Form submission has a pending guard and disabled controls. Save now
joins an existing dossier save before sending later edits. Stable IDs and content
comparison make identical retries idempotent, including an initial creation whose
response was lost. Trash actions also disable their pending button.
VERIFIED: duplicate-submit and save-joining regressions, creation-retry/history
checks, real browser double-click and Trash workflows.

06. There is no useful change history or undo
IMPLEMENTED. Every changed save stores a full revision, timestamp and action.
Shared-record changes, migration, Trash and restore also create history entries.
History can inspect and restore a snapshot as a new revision. Removal offers
immediate Undo; permanent removal explicitly deletes that dossier's history.
VERIFIED: history/revision restoration, Trash/restore and permanent-removal checks.

07. Matching names are treated as matching identities
IMPLEMENTED. Entity IDs determine identity. Same names remain separate. Legacy
external endpoint occurrences receive distinct IDs. Identity review suggests
name/alias matches, explains ambiguity, and requires an analyst's merge decision.
The original legacy record remains available for comparison.
VERIFIED: namesake graph and conservative-migration regressions; the current
sample contains two distinct Morgan Example identities.

08. Entity types are incomplete and inconsistent
IMPLEMENTED. Person, Organization, Account, Domain, Project and Other entity are
explicit choices, persisted on the entity and used consistently by the map.
The dossier's subject must retain a Person or Organization type.
VERIFIED: typed graph nodes and backend entity/subject validation.

09. Repeated links overlap and resemble stronger evidence
IMPLEMENTED. Identical endpoint/relationship edges are grouped with the number
of underlying records. Every evidence record retains its confidence, excerpt and
source links. Different relationships use separated curves. Shared source pages
are represented once in a case graph, with their dossier-specific references.
VERIFIED: duplicated-link graph regression and edge inspection in Chromium.

10. Source references are fragile text
IMPLEMENTED. Assertions store source IDs; references such as S01 are editable
labels. Duplicate reference labels and canonical URLs within a dossier are
rejected. Quick capture reuses a known URL. Referenced sources cannot be removed
without reassigning evidence. Imports check dangling links and duplicates.
VERIFIED: stable-link/ref-generator, URL/reference validation and legacy source
consolidation checks.

11. Evidence is not tied to a particular assertion
IMPLEMENTED. Facts and connections have assertion IDs. Evidence links run from
an assertion node to its source. Relationship inspection lists the precise
underlying assertions, each with evidence, source references, dates and confidence.
VERIFIED: assertion-level graph regression and browser relationship inspection.

12. Unsupported claims can look strongly confirmed
IMPLEMENTED. Reviewed, Confirmed or Corroborated assertions need linked sources
or an explicit evidence justification. Unsupported entries are labeled visibly;
provisional relationship lines are dashed and contradicted ones are dotted/red.
Legacy unsupported strong certainty is flagged and downgraded for review, with
the original classification retained in the archive.
VERIFIED: backend promotion rejection and browser confidence/evidence inspection.
A source link establishes traceability; the analyst must still assess its content.

13. Confidence has conflicting meanings
IMPLEMENTED. All assertions use one six-level evidence taxonomy. Review state is
separate from confidence, and source quality is separate from both. The same
record supplies every list, map, timeline and report. Unresolved assertions can
be reviewed together, including both facts and relationships.
VERIFIED: model validation, graph/report values and unresolved-view implementation.
Legacy Low/Medium/High conversions are explicit and their originals are retained.

14. Numerical scores look precise without a rubric
IMPLEMENTED. Scoring is optional, internal by default, and labeled analyst
judgment. Anchors describe 0, 2, 5, 8 and 10. Each entered dimension needs a
purpose-specific explanation; blank dimensions can be omitted. Scores do not
stand in for evidence confidence or require completing an irrelevant worksheet.
VERIFIED: range/reasoning rejection tests; scoring prompts and explanations were
reviewed in code. Agreement between human analysts remains a research judgment.

15. Imports accept malformed values and unsupported versions
IMPLEMENTED. Versions, object/list types, stable IDs, references, dates, URL
schemes/ports, uniqueness, entity endpoints, review state and certainty support
are validated before acceptance. Approximate years/months remain explicit.
Older data is previewed and conservatively migrated; its original data is kept.
New-copy import regenerates entity and source IDs so unrelated copies stay separate.
VERIFIED: bad-version/date/URL/reference/shape regressions and browser import rejection.

16. The default worksheet is too large
IMPLEMENTED. The default product starts with Overview, Facts, Connections,
Sources and Next steps. The map, timeline and history are additional views.
The supplied detailed templates are optional prompts, rather than 90 empty fields.
VERIFIED: laptop/mobile core workflows and inspected interface screenshots.

17. The same fact belongs in too many places
IMPLEMENTED. One maintained assertion supplies lists, map nodes, the timeline,
reports and supporting conclusions. Conclusions refer to existing assertion IDs.
Working notes stay separate from sourced claims. Legacy repetition is retained
for recovery and explicit analyst review rather than silently discarded.
VERIFIED: stable assertion/source projections and graph/report regressions.

18. Help lacks concrete next actions
IMPLEMENTED. Larger ? targets show guidance on hover/focus and open a pinned
panel on click. Guidance includes a concrete example and where/how to obtain the
information. Dates, URLs, source titles, publishers, evidence, aliases and identity
details have specific instructions. Forms have explicit accessible labels.
VERIFIED: browser guidance dialogs, including inside a native modal, plus visual QA.

19. The worksheet cannot be adapted
IMPLEMENTED. Optional modules, selectable person/organization prompts, ownership
prompts, custom labels/categories and personal presets are available. Saved
presets can be applied to a new dossier. Prompts become maintained assertions,
not another parallel worksheet database.
VERIFIED: custom Ownership prompt/preset browser workflow at both screen sizes.

20. Blank fields do not explain unknown information
IMPLEMENTED. Known, Not checked, Not found and Not applicable are explicit states.
Known assertions require a value. Documented negative results can record where
the analyst looked. Optional new prompts begin as Not checked.
VERIFIED: backend knowledge-state checks and browser negative-result/preset workflows.

21. One web finding takes too much repeated typing
IMPLEMENTED. Quick capture records a fact and its source together, prefills the
collection date, and reuses a known URL. Existing sources can be selected for
further facts instead of retyped. Forms preserve unfinished capture data.
VERIFIED: browser capture workflow and draft-with-source recovery regression.

22. Timeline chronology is incomplete
IMPLEMENTED. Actual event dates, collection dates and publication dates are
separate modes. Source publication dates are included in publication chronology.
Year/month precision stays explicit, and undated assertions remain listed.
VERIFIED: date validation and timeline projection review; entries remain editable
through the same assertion records.

23. Separate dossiers are not a shared investigation
IMPLEMENTED. Cases have objectives and organize dossiers. Connections can
explicitly select another dossier's subject ID, and source entry can reuse an
existing case source. Shared metadata updates are transactional and create
revisions in linked live dossiers. A whole-case map refreshes and joins records
by identity IDs, never by matching names.
VERIFIED: shared-record atomicity/stale-write checks and real browser case/source/
identity reuse workflows at laptop/mobile sizes.

24. The graph cannot support editing
IMPLEMENTED. The inspector opens the exact fact, relationship, source or identity
editor and can jump to another linked dossier. Edits use the maintained records
and appear in the lists and reports. Missing linked dossiers are reported instead
of pretending that a record was edited.
VERIFIED: inspected edge/node actions and case linking browser workflows.

25. Search and filtering remove context
IMPLEMENTED. Search covers names, properties and relationship labels. It includes
relevant endpoints and supporting records without pulling every unrelated fact
from a matching endpoint. Type filtering retains connected context. Small search
results receive a focused layout while manually dragged positions remain protected.
VERIFIED: edge-label search/context regression and real browser searches.

26. Dense maps become tiny and Fit can crop them
IMPLEMENTED. Large maps start with a limited neighborhood. More neighbors and
Show all are deliberate expansion choices. Fit uses actual visible bounds without
a restrictive minimum zoom. Readable node labels/glyphs are maintained for small
views, labels wrap on narrow screens, and dense overview labels yield to zoom/
selection rather than covering one another. Fullscreen and Hide details add space.
VERIFIED: 501-node DOM geometry, 500 connected identities in Chromium at both
sizes, rendered bounds and inspected mobile screenshots.

27. Graph arrangements disappear
IMPLEMENTED. Positions, manually arranged nodes, camera, selection, filters,
evidence visibility and expansion/collapse state are persisted per dossier/map
scope. Included graph layout is carried into offline exports; excluded IDs and
source URL metadata are removed from that exported view state.
VERIFIED: saved-position regression, leave/reopen browser scenario and offline export.

28. Inspecting a graph node loses keyboard focus
IMPLEMENTED. SVG nodes and edges retain their DOM elements during redraws.
Enter inspects, arrow keys expand/collapse, and a separate accessible record list
supports navigation. Inspecting a node keeps focus on that node.
VERIFIED: DOM and Chromium focus assertions.

29. Headline counts are misleading
IMPLEMENTED. The dashboard shows unique source records, unresolved assertions
and open next steps. Clicking each opens its corresponding records; unresolved
includes relationships and facts, and open next steps excludes completed tasks.
Map status separates visible nodes, identity coverage and edges.
VERIFIED: dashboard/list implementation and browser workflow screenshots.

30. Export leaks everything despite graph filters
IMPLEMENTED. Dossier export has reviewed/internal presets, specific assertion
selection and explicit notes/leads/summary/archive controls. An exact preview
shows what will be included. Exclusions happen before JSON/HTML serialization;
only referenced entities/sources and permitted layout metadata are carried.
Public output uses known fields, preventing unknown private properties leaking.
VERIFIED: excluded-note/lead/archive/private-field regression and downloaded offline
HTML inspected and opened with networking disabled in Chromium.

31. There is no readable final assessment
IMPLEMENTED. Text and printable HTML reports include selected facts/connections,
evidence, confidence, source citations, event/publication/collection dates and
limitations. Investigation question, conclusions/supporting references, notes and
next steps are explicit optional inclusions. Conclusions remain analyst-authored.
VERIFIED: report-content regressions and browser exact-preview/export workflows.

32. Starting and troubleshooting requires technical effort
IMPLEMENTED. Launch OSINT Mapper.cmd opens a local Start/Open/Stop/status launcher.
The browser shows live connection state and explicit saved/pending/failed status.
Port conflicts, writable-folder problems, damaged databases and full disks receive
specific recovery messages. Long requests time out with the draft still protected.
VERIFIED: actionable launcher-error checks, server health/host checks, actual local
startup/restart and browser connectivity. The native launcher window was not
interactively inspected: the Windows Computer Use helper was unavailable.

33. Backup and storage protection are outside the workflow
IMPLEMENTED. In-app full-workspace backup/restore includes cases, dossiers,
Trash and history. SQLite's backup API creates dated snapshots, including before
migration/restore. Optional downloads are encrypted in the browser. Restoration
is validated before replacement and preserves a safety backup. Old drafts are
retained separately instead of being silently applied to restored records.
VERIFIED: backend backup roundtrip/rejection and Chromium encrypted download,
wrong-password rejection, unlock/inspection and full restoration at both sizes.
The database, ordinary SQLite snapshots and browser drafts remain plaintext;
the interface and README state this local single-user security model.

34. Trash has no deliberate permanent removal
IMPLEMENTED. Recoverable deletion remains the default. Permanent removal is an
explicit confirmed Trash action, deleting the live dossier and history plus its
draft/layout copies in this browser. Backups, exports and independent records in
other dossiers are not claimed to be erased.
VERIFIED: backend history/purge checks and Chromium delete/restore/purge scenarios.

35. Tests do not represent analyst failures
IMPLEMENTED. Frontend regressions and real Chromium workflows are committed and
reproducible. They cover delayed/failed writes, competing tabs, protected forms,
identity ambiguity, maintained sources, selective export, focus, fullscreen,
500-node maps, long notes, module presets, imports, shared cases and recovery.
VERIFIED: 19 backend + 12 frontend + 20 browser checks passed. SQLite integrity
and verbatim preservation of existing dossiers were verified separately.

CURRENT LIMITS

- This is still a manual OSINT recording tool, not an automated collector.
- Strong certainty needs traceability/justification, but source quality and real
  identity matches require analyst judgment. Names or link counts do not prove them.
- Existing legacy ambiguities are preserved and flagged, not resolved by guessing.
- Encrypted backup downloads do not encrypt the live database or browser drafts.
- Exports are snapshots of the selected dossier; the workspace backup covers
  all cases and history. Graph filters are not data redaction controls.
- Chromium received automated laptop/mobile QA. Other browser engines and the
  native Windows launcher require an interactive visual pass in their own environment.
- No test suite can guarantee that every future case will be comfortable to use;
  the reproduced faults now have fixes and regression coverage where automatable.
